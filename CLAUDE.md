# Project

This is a Pokemon data builder project that allows me to store, modify, and manipulate pokemon data to better suit me needs for my Pokemon website. It then gets uploaded to mongodb.

# Practices to follow

- Line lengths shouldn't be more than 80 characters
- Functions shouldn't be more than 30 lines long and should follow the single responsibility rule.
- Variable names should describe the variable, no single character variable name.

- Clean Code A Handbook of Agile Software Craftsmanship by Robert C. Martin

# Commands

- Don't ask me to run `node -e ' *`

# Code Style
- Use 4 space indentation
- Prefer named exports
